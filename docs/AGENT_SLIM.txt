DOWNGRADE (legacy / opt-in)
==============================================================================

Imperative chat runtime
  services/agent/conversation.py::_chat_imperative / _stream_chat_imperative
  Env: LIVEHOUSE_AGENT_RUNTIME=imperative|loop|legacy
  Default is LangGraph; missing langgraph → hard error (no silent fallback).
  Kept for tests + emergency only.

Native OpenAI tools[] on chat (experimental A/B)
  Env: LIVEHOUSE_AGENT_NATIVE_TOOLS=1
  build_chat_fn(..., tools=registry.tool_specs()) attaches tools; native tool_calls
  are bridged back to {"tool","args"} text JSON for the existing decide→act loop.
  Default off — production stays on text protocol.
