RUNTIME MATRIX (who decides what)
==============================================================================

  Intent path × Model protocol (production defaults in bold)

  ┌──────────────────┬────────────────────────────┬──────────────────────────┐
  │ Control path     │ Model protocol             │ When                     │
  ├──────────────────┼────────────────────────────┼──────────────────────────┤
  │ intent_router    │ (no tool JSON round)       │ High-freq recipe asks    │
  │ **langgraph**    │ **plan or {"tool","args"}**│ Semantic plan / fallback │
  │ langgraph        │ native tools[] (bridge)    │ LIVEHOUSE_AGENT_NATIVE_  │
  │                  │ multi → __multi__ serial/  │ TOOLS=auto (openai/vllm  │
  │                  │ parallel read-only         │ on; ollama off) or 1/0   │
  │ imperative       │ text {"tool","args"}       │ LIVEHOUSE_AGENT_RUNTIME= │
  │                  │                            │ imperative (emergency)   │
  └──────────────────┴────────────────────────────┴──────────────────────────┘

  Missing langgraph → hard error (no silent fallback).
  Ownership: always anon:<session_id> (login auth removed from product surface).
  SSE ``token`` = typing-effect over finalized reply (buffer → {ref_N} resolve /
  groundedness template gate → chunk). Not true token-level model streaming.
  Final-answer cites: model emits {ref_N}; code substitutes metadata.files.
  LangGraph: START→plan→(execute_plan | decide→act)→answer. Structured semantic
  selection goals use deterministic execute_plan and skip the model tool round.
  After file-bearing tools, answer() prefers lean PHOTO REFS prompt
  (ignores decide-loop prose). No-file tools (echo/stats) still use direct_reply.
  answer() branches: ANSWER_BRANCH_CHECKLIST in conversation_graph.py — keep in
  sync with TestAnswerBranch* (@pytest.mark.requires_langgraph). Missing
  langgraph → those tests FAIL (tests/conftest.py), never silent imperative.
  Vision: focus_file thumbnail when LIVEHOUSE_AGENT_VISION=1 (default).
  Façade: services/agent/runner.py (AgentSession / AgentRunner).

DOWNGRADE (legacy / opt-in)
==============================================================================

Imperative chat runtime
  services/agent/conversation.py::_chat_imperative / _stream_chat_imperative
  Env: LIVEHOUSE_AGENT_RUNTIME=imperative|loop|legacy
  Default is LangGraph; missing langgraph → hard error (no silent fallback).
  Kept for tests + emergency only.

Native OpenAI tools[] on chat
  Env: LIVEHOUSE_AGENT_NATIVE_TOOLS=auto|1|0
  auto (default): attach tools for openai/vllm; ollama stays text-protocol.
  Native tool_calls bridge via tool_protocol (N calls → __multi__).

CLIP hybrid search (tag/caption ∪ text→image, score re-rank)
  Env: LIVEHOUSE_AGENT_SEMANTIC_FALLBACK=0 disables CLIP; LIVEHOUSE_AGENT_SEMANTIC_HYBRID=0
  → legacy fallback-only. Index-on-analyze: LIVEHOUSE_EMBED_INDEX_ON_ANALYZE=0 to disable.
  Slow-shutter stays EXIF-only (never CLIP).
