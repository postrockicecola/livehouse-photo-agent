# Agent eval contract (Phase 0)

Status: **frozen for L0**. Companion schemas live under `quality/schemas/`.

## Assets

| Path | Role |
|------|------|
| `cases.v1.jsonl` | L0 scripted / routed Gallery chat cases (`agent_chat_case.v1`) |
| `router_paraphrases.v1.jsonl` | Intent-router positive / negative paraphrases |
| `sessions/<name>/analysis_results.json` | Tiny fixture galleries for skills |

Pipeline photo goldens (`data/eval/labels.jsonl`, `quality/schemas/golden_item.schema.json`) stay separate. The `agent_chat` split on media goldens only means “may be referenced by an agent case”, not that the row is an agent utterance.

## Case join keys

| Field | Rule |
|-------|------|
| `id` | Stable snake_case; never reuse for a different intent |
| `session` | Folder name under `sessions/`; default `smoke` |
| `split` | `smoke` \| `core` \| `regression` \| `hard` |
| `expect.route` | `intent_router` `rule_id`, or JSON `null` when the tool loop must run |

## L0 runner

```bash
python -m scripts.eval.eval_agent_chat_cases
python -m scripts.eval.eval_agent_router_paraphrases
python quality/validate_contracts.py quality/schemas/examples/agent_chat_case.example.json
```

CI expectation: both eval scripts exit 0; protocol + router paraphrase tests green.

## Groundedness (Phase 2)

Runtime: ``services/agent/groundedness.py`` rewrites final replies that cite
image basenames absent from this turn's tool metadata / working-memory
``last_files``. L0 cases may set ``expect.grounded`` and
``expect.reply_must_not_contain``.

## L1 live (Phase 3)

Cases with ``"live": true`` enter ``scripts/eval/eval_agent_live.py``.

```bash
python -m scripts.eval.eval_agent_live --mock --suite smoke   # CI
python -m scripts.eval.eval_agent_live --mock --suite core
python -m scripts.eval.eval_agent_live --live --suite smoke   # needs chat model
```

Metrics: ``pass_at_1``, ``tool_name_acc``, ``route_acc``, ``grounded_rate``,
``json_leak_rate``, ``empty_honesty_rate``, ``p50/p95_latency_ms``, plus
``prompt_hash`` + model metadata. Mock mode is a CI gate; ``--live`` is
informational (exit 0) until a release threshold is frozen.

## Observability + promotion (Phase 4)

Each turn's ``done`` event / ``ChatResponse.trace`` includes:

``backend``, ``rule_id``, ``rounds_used``, ``grounding_ok``, ``parse_fail``,
``guardrail_matches``, ``json_leak``.

Weekly loop::

    python -m scripts.agent.export_review_queue --days 7
    # annotate issue_type / expected_behavior / action
    python -m scripts.agent.promote_to_fixtures data/review_queue/<day>.jsonl
    python -m scripts.eval.report_agent_quality_weekly \\
        --review data/review_queue/<day>.jsonl \\
        --out data/eval/agent/reports/weekly.md

Promote targets: router fixtures, ``router_paraphrases.v1.jsonl``, and chat
``cases.v1.jsonl`` stubs (hallucination / grounding / parse).

## Protocol repair + guardrail policy (Phase 5)

- Broken tool JSON that still *looks* like a tool call gets **one** repair
  completion (``services/agent/tool_protocol.py`` / ``resolve_tool_decision``);
  failures set ``trace.parse_fail`` / emit ``parse_repair``.
- Native ``tool_calls`` bridge also lives in ``tool_protocol`` (re-exported by
  ``chat_backend``).
- Guardrail policy via ``LIVEHOUSE_AGENT_GUARDRAIL_POLICY``:
  ``observe`` (default) | ``soft`` | ``hard``.
- Turn trace contract: ``quality/schemas/agent_turn_trace.schema.json``
  (``schema_version: agent_turn_trace.v1`` on ``ChatResponse.trace``).
- Search data: ``data/agent/query_synonyms.jsonl`` +
  ``data/agent/search_recipes.json``; CI smoke runs
  ``measure_gallery_search_gaps`` on the smoke fixture and fails only when
  *in-table / case* probes regress to ``empty_synonym_gap`` (OOV probes stay
  informational).

## Human / LLM judge (Phase 6)

Rubric (1–5 only): ``useful``, ``honest``, ``concise``.
Hard gate: file cites must be grounded (same rules as production). Ungrounded
turns fail even if the judge scores 5/5.

```bash
python -m scripts.eval.eval_agent_judge --mock --suite smoke
python -m scripts.eval.eval_agent_judge --live --suite smoke
python -m scripts.eval.eval_agent_judge --human path/to/ratings.jsonl
python -m scripts.eval.eval_agent_judge --mock --suite smoke \
  --promote-stubs data/review_queue/judge_fails.jsonl
```

Human example: ``quality/schemas/examples/agent_rating.example.json``.
Failing ratings → review stubs → ``promote_to_fixtures``.
