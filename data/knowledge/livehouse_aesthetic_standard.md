# 基本原则

Livehouse 摄影首先记录真实演出，其次通过瞬间、光线、空间和人物关系表达现场感。
技术正确不等于作品优秀，技术瑕疵也不必然意味着淘汰。所有判断都应结合创作意图、
使用场景和整组叙事。

# 张力

张力是多个视觉信号共同形成的结果：

- 动作峰值：拨弦、挥槌、跳跃、身体倾斜和明确手势。
- 情绪峰值：嘶吼、闭眼投入、对视、笑容或高度专注。
- 方向冲突：人物视线、乐器、灯束和肢体形成相互作用。
- 空间压缩或扩张：拥挤前排、留白、极近距离或大舞台尺度。
- 光影冲突：明暗分离、逆光轮廓、烟雾光束和色彩对撞。

不能把高对比度单独等同于张力。没有主体、动作和情绪支撑的高对比照片仍可能空洞。

# 瞬间与叙事

高分瞬间应具备明确事件：独奏进入高潮、鼓槌即将落下、乐手互动、主唱与观众呼应、
跳跃腾空或谢幕。动作前一刻和后一刻都可能比动作正中更有力量，应检查完整连拍。

整组照片需要建立节奏：

- 开场：环境、人物登场或舞台建立镜头。
- 发展：人物特写、乐器细节和灯光变化。
- 高潮：最强动作、表情和互动。
- 收束：观众、谢幕或演出后的余韵。

# 光线与色彩

保留舞台灯的真实个性，不追求所有照片统一为自然肤色。评价重点是：

- 主体是否能从背景中分离。
- 关键五官、手部和乐器是否保留必要信息。
- 高光是否形成视觉中心，而不是无意义溢出。
- 色彩关系是否服务情绪，而不是互相污染。
- 暗部是否有层次，或剪影是否具有清楚轮廓。

剪影只有在轮廓、动作和背景关系明确时成立。单纯曝光不足不能作为风格解释。

# 构图

优先检查：

- 人物视线、动作方向和画面留白是否匹配。
- 乐器琴头、手、鼓槌和肢体关节是否被不自然切断。
- 麦克风、支架和前景遮挡是否破坏脸部或动作。
- 倾斜是否增强动势；无意倾斜应校正。
- 画面边缘是否出现无意义肢体、强光或杂物。

平台裁切必须在原始构图允许的范围内进行。不能为了竖版而破坏核心动作。

# 技术质量

技术评分关注：

- 对焦点是否落在叙事主体或关键动作上。
- 快门是否产生符合意图的凝固或拖影。
- 曝光是否保留主体信息和舞台灯层次。
- 高 ISO 噪点是否仍具有可接受的纹理。
- 降噪和锐化是否造成塑料感、光晕或细节断裂。

慢门、拖影、颗粒、欠曝和失焦只有在形成清楚视觉意图时才属于可接受偏离。

# 主体与人物关系

人物照片不能只依赖人脸面积评分。优秀画面可能通过手部、乐器、背影或人物之间的关系
表达现场。若用于艺人交付，则需要提高主体完整度、识别度和形象风险检查。

# 建议评分解释

Agent 给出推荐理由时，应指出可观察证据，例如：

- “拨弦动作和面部表情同时到达峰值。”
- “蓝色逆光把人物轮廓从烟雾背景中分离出来。”
- “吉他琴颈与灯束形成对角线，增强动作方向。”

避免只说“很有感觉”“氛围很好”或“评分很高”。解释必须与图像分析字段或人工标签对应。

# 人工校准

本标准需要用真实摄影师评审持续校准。每次模型版本调整后，应检查：

- 高分照片是否真的更适合交付。
- 特殊风格是否被技术门槛误杀。
- 不同艺人、灯光、肤色和机位是否存在系统偏差。
- 推荐理由是否与摄影师实际判断一致。
