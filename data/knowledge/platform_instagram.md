# 适用范围

本规范用于 Livehouse 摄影作品的 Instagram Feed、Carousel、Stories 和 Reels 发布准备。
具体上传限制、推荐尺寸和社区规则以 Instagram Help Center 与 Meta Business Help Center
的最新说明为准。

# Feed 与 Carousel

内部制作可采用以下常见工作尺寸作为导出起点，而不是平台永久承诺：

- 竖图：4:5，常用工作尺寸 1080 × 1350。
- 方图：1:1，常用工作尺寸 1080 × 1080。
- 横图：约 1.91:1，常用工作尺寸 1080 × 566。

同一 Carousel 的显示比例可能受首张图片影响。发布前需要在真实上传界面预览，
确认后续照片没有被意外裁切。音乐人肖像优先检查头部、手部、乐器和舞台关系。

# Stories 与 Reels

Stories 和 Reels 通常以 9:16 竖屏工作画布准备，常用尺寸为 1080 × 1920。
重要人物、文字和品牌元素应远离顶部、底部及界面按钮覆盖区域。
具体安全区随设备和客户端界面变化，不应写死为永久像素值。

# 选片与排序

Feed 首图需要在网格缩略图和信息流两种场景下成立。建议按以下优先级选择：

1. 主体识别度与瞬间强度。
2. 色彩和光影在小尺寸下的辨识度。
3. 与账号整体视觉风格的一致性。
4. Carousel 内景别、人物和节奏的变化。
5. 技术质量以及导出后的细节保持。

一组 Livehouse 照片可以采用“强人物首图—动作特写—乐手互动—舞台全景—观众或谢幕”
的结构。不要用十张相似连拍代替叙事。

# 导出建议

- 使用适合网页发布的 sRGB 色彩空间。
- 先完成裁切、降噪、锐化，再输出最终文件，避免重复压缩。
- 检查暗部色块、灯光渐变断层、锐化光晕和高 ISO 彩噪。
- 保存一份不含平台二次压缩的高质量母版。
- 发布后若平台压缩严重，优先检查源文件尺寸、压缩次数和锐化策略。

# 内容与权利

- 不发布未经授权的后台、休息区或艺人私人状态。
- 不虚构演出事实、合作关系、品牌背书或人物言论。
- 商业合作、赠品或广告内容按照 Meta 当期规则进行披露。
- 音乐、视频片段和图片都需要分别确认使用权限。
- 社区准则和账号状态可能影响内容分发，出现异常时应检查官方账号状态页面。

# Agent 使用规则

当用户要求“发 Instagram”“做 Carousel”或“适配 Reels”时，Agent 应：

- 区分 Feed、Carousel、Stories 和 Reels。
- 把常见工作尺寸表述为制作建议，而不是未经核验的强制规则。
- 对裁切风险给出具体说明，特别是脸部、手部和乐器边缘。
- 引用本文件时使用 `platform_instagram.md#chunk-N`。
- 涉及最新限制时引导用户核对 Instagram Help Center。
