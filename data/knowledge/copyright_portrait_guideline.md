# 声明

本文件是工作室风险检查清单，不构成法律意见。具体项目应结合合同、拍摄地点、
授权范围、商业用途和适用法律判断。高风险或存在争议的使用应咨询专业律师。

# 摄影作品与著作权

摄影作品可能受到著作权保护。拍摄者、受雇关系、委托创作合同和权利转让条款都会影响
实际权利归属。不能仅凭“照片在自己的相机里”推断拥有所有使用权。

项目开始前应明确：

- 谁是摄影作品的作者或权利人。
- 客户获得的是所有权、著作权转让，还是特定范围的使用许可。
- 许可包含哪些媒体、地区、期限和商业用途。
- 摄影师是否保留作品集、比赛、社交媒体和宣传用途。
- 是否允许二次编辑、转授权、AI 训练或素材库使用。

# 肖像与人格权益

可识别自然人的照片可能涉及肖像、隐私和个人信息权益。公开活动并不自动意味着照片可以
用于所有商业用途。新闻记录、艺术表达、个人分享、品牌广告和商品包装的风险不同。

发布前应检查：

- 人物是否可以直接或结合场景被识别。
- 是否存在明确授权、活动告知或合同依据。
- 使用方式是否超出被摄者可合理预期的范围。
- 文案是否造成虚假代言、贬损、误导或敏感身份关联。
- 是否涉及未成年人、后台私人空间或脆弱状态。

# Livehouse 场景

演出摄影通常同时涉及艺人、观众、场地方、主办方和品牌。至少确认：

- 拍摄证或媒体证允许的拍摄区域与时间。
- 场地方和主办方对闪光灯、后台、前三首歌及发布时点的限制。
- 艺人或经纪方对审核、独家、禁发照片和商业使用的约定。
- 观众近距离可识别肖像是否需要弱化、裁切或取得授权。
- 舞台屏幕、视觉作品、品牌标识和演出内容是否有额外限制。

# 客户资料与权限

客户 brief、合同、联系人、报价、未发布照片和修改记录可能包含商业秘密或个人信息。
Knowledge RAG 只应索引完成脱敏并被批准进入知识库的内容。

最低要求：

- 删除姓名、电话、邮箱、证件、地址、账号和付款信息。
- 每份文档设置正确的 `tenant` 与 `allowed_owners`。
- 默认不把客户原始合同设置为公开 `allowed_owners: ["*"]`。
- 不把未公开照片、后台照片或客户资料发送给外部模型，除非已有授权和数据处理约定。
- 保留数据来源、更新时间、授权依据和删除流程。

# 发布前权利检查

1. 确认照片来源和文件版本。
2. 确认合同或授权覆盖当前用途。
3. 检查人物、商标、艺术作品、票据和敏感信息。
4. 检查文案是否暗示未经确认的合作或代言。
5. 对高风险内容升级人工审核。
6. 记录批准人、发布时间、平台和使用范围。

# 删除、撤回与争议

收到权利人、客户、艺人或观众的合理异议时，不应由 Agent 自动作出法律结论。
应保存请求内容，暂停进一步传播，核对合同与授权，并交由项目负责人处理。
删除线上内容不等于删除所有备份，应按照内部保留与删除政策同步执行。

# Agent 行为边界

- Agent 可以提供检查清单和指出缺失信息，不能声称已经获得授权。
- Agent 不得根据照片猜测敏感身份、健康、政治观点或其他受保护信息。
- 没有可靠证据时，应回答“授权状态未知，需要人工确认”。
- 法律条款和平台政策需要引用可核验来源，并注明更新时间。
- 涉及具体争议、赔偿、诉讼或合同解释时，建议咨询专业律师。
