# 适用范围

本规范用于 Livehouse 摄影作品的小红书选片、裁切、文案和发布前检查。
它是工作室内部操作建议，不替代小红书创作服务平台、社区规范或品牌合作规则。
平台规则可能调整，发布人员应在重要项目上线前重新核对官方页面。

# 选片目标

每组作品需要在前三张内建立明确主题。优先选择主体清楚、动作或情绪处于峰值、
灯光具有辨识度并且缩略图下仍然成立的照片。

对于“最有张力”的请求，按以下维度综合判断：

- 动作与表情峰值：拨弦、击鼓、跳跃、嘶吼、肢体伸展或明确互动。
- 现场感染力：艺人与观众、乐手之间或人物与舞台环境之间存在关系。
- 光影与色彩：轮廓分离清晰，明暗和色彩有戏剧性，但不能因追求氛围而丢失主体。
- 构图：视觉中心稳定，裁切后不破坏乐器、手部、脸部或关键动作。

# 画幅与裁切

工作流默认优先准备竖向版本，因为移动端信息流中通常具有更大的展示面积。
内部推荐优先尝试 3:4；如果原片不适合竖裁，则保留横构图，不为适配平台强行切断
吉他琴头、鼓槌、手掌、脸部或舞台互动关系。

Instagram 常见的 4:5、Reels 常见的 9:16 等规格不能直接视为小红书官方固定要求。
最终像素、比例、文件大小和视频参数应以发布当日的小红书官方上传界面为准。

# 组图编排

建议一组包含 6 至 12 张，具体数量由叙事完整度决定：

1. 首图：最强视觉记忆点，主体和动作一眼可辨。
2. 第二至三张：补充人物身份、乐器或表演关系。
3. 中段：全景、互动、观众和环境，建立现场叙事。
4. 结尾：情绪余韵、谢幕、空舞台或具有结束感的画面。

避免连续放入高度相似的连拍。除非动作演进本身有叙事价值，同一连拍通常只保留一张。

# 技术质量门槛

- 主体失焦、严重运动模糊或关键五官无法辨认时，不进入首选。
- 高光大面积不可恢复、暗部完全堵塞且影响主体时，应降级或淘汰。
- 噪点可以作为现场质感保留，但彩色噪点、条带和过度锐化不能明显干扰观看。
- 舞台灯造成的偏色可以保留；肤色失真到影响人物识别时需要调整。
- 不得通过生成式工具虚构不存在的艺人、观众、品牌或舞台事实。

# 文案与标签

文案应说明真实的演出、人物、场次或拍摄感受，不虚构艺人言论和现场事件。
标签以内容相关性为先，避免堆叠无关热门词。涉及品牌合作、商业推广或赠品时，
按照平台当期要求进行标识。

# 权利与隐私检查

- 确认作品发布权、客户授权和场地方规则。
- 未成年人、后台私密区域、票据二维码、电话号码和证件信息需要特别检查。
- 对观众近距离可识别肖像，结合授权、活动告知和使用场景评估风险。
- 接到合理删除或撤回请求时，保留处理记录并及时响应。

# Agent 使用规则

当用户提出“小红书选片”时，Agent 可以将本规范作为排序与解释依据，但必须：

- 将平台建议与硬性规则区分开。
- 不声称未经核验的像素或比例是官方强制要求。
- 引用本文件时使用 `platform_xiaohongshu.md#chunk-N` 来源标识。
- 若问题涉及最新平台政策，明确建议用户再次检查官方创作服务平台。
